# ☁️ FOCUS Multi-Cloud

> Aplicação web de automação e preparação de dados para BI, voltada a custos multi-cloud e baseada no padrão FOCUS.

---

## 📖 Sobre o projeto

O **FOCUS Multi-Cloud** é uma aplicação web desenvolvida como Trabalho de Conclusão de Curso (TCC) para automatizar o tratamento e a padronização de dados de custos provenientes de diferentes provedores de computação em nuvem.

A aplicação recebe arquivos de custos, identifica sua origem, realiza o tratamento e mapeamento das informações e converte os dados para uma estrutura baseada no padrão **FOCUS (FinOps Open Cost and Usage Specification)**.

Após o processamento, os dados podem ser explorados por meio de tabelas e visualizações e exportados para utilização em análises e ferramentas de Business Intelligence (BI).

> ⚠️ *Projeto em desenvolvimento.*

---

## ✦ O que fazemos?

Dados de custos de diferentes provedores podem apresentar estruturas, nomenclaturas e formatos distintos. O FOCUS Multi-Cloud busca simplificar esse processo:

`Entrada` → `Detecção` → `Tratamento` → `Padronização FOCUS` → `Análise`

A proposta é transformar diferentes formatos de dados em uma estrutura comum, facilitando sua utilização em análises de custos e processos de FinOps.

## 📊 Funcionalidades

- Upload de arquivos de custos cloud
- Identificação automática do provedor
- Tratamento e normalização dos dados
- Mapeamento de campos específicos de cada provedor
- Aplicação de regras de transformação para adequação ao FOCUS
- Padronização da estrutura de saída
- Exploração dos dados processados
- Visualização por meio de gráficos
- Exportação dos dados padronizados
